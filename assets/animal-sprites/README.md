# World Tour walking animals

Each named WebP is a transparent, four-frame horizontal sprite strip (1536 × 288 pixels). Frames are 384 × 288 pixels, ordered left to right: stride, raised foreleg/flipper, opposite stride, opposite raised foreleg/flipper. All animals face right; the game flips the image when they walk left.

The 18 species are cat, wolf, boar, ibex, chamois, bear, stag, fox, tanuki, macaque, camel, oryx, tiger, jackal, jaguar, capybara, coyote, and sea lion (`seaLion.webp`). `preview.webp` is a labeled overview of their first frames. The World Tour rat continues to use its existing drawn animation.

The images were made to match the supplied animal collage. The game uses one image per species, including repeated species on later stages, and loads each image as needed.
