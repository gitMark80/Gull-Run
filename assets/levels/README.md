# Hudson stage artwork

Created with the built-in image generator for Gull Run Evo. The ferry preserves transparency. WebP copies are bundled for gameplay.

Background brief: polished cartoon/anime panorama from Manhattan's Hudson seawall toward New Jersey, with Statue of Liberty, navy starfield transitioning to blue sky, skyline, turquoise river, stone seawall and paved promenade. No vehicles, characters, interface, text, or red boundaries. Stylized geography, not a navigation map.

Ferry brief: standalone white two-deck Hudson passenger ferry facing right, transparent background, blue reflective windows, railings, orange life rings, mast, dark rubber bumpers, shaded painted metal and navy outlines. No logos, text, people, water rectangle or other objects.

The game maps background bands into the existing flight/water/ground zones, and animates the ferry's position, direction and bobbing. Two environments alternate as levels are cleared.
