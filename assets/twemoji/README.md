# Twemoji artwork

The original SVGs come from https://github.com/jdecked/twemoji/tree/main/assets/svg. Files ending in -detailed.svg are adaptations for Gull Run Evo, adding gradient shading, green food outlines, and sailboat rigging, seams and portholes.

Used for burgers, hot dogs, pizza, coins, diamonds and sailboats. The game adds motion and shadows during rendering. These images are openly licensed, not public domain. This license does not cover the separate character/background artwork.
